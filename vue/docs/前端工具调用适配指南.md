# 前端工具调用适配指南

## 概述

工具调用（Function Calling）开启后，SSE 事件流新增了 `tool_start`、`tool_end` 事件类型。前端需要处理这些新事件，向用户完整展示"AI 思考 → 调用工具 → 工具返回 → AI 回复"的全过程。

---

## 一、SSE 事件类型汇总

### 1.1 完整事件表

| 事件类型 | 触发方 | 含义 | 用户可见? |
|----------|--------|------|-----------|
| `content` | AI | 正文输出增量文本 | ✅ 直接展示 |
| `reasoning` | AI | 深度思考过程（仅在 deep-thinking 模式） | ✅ 折叠展示 |
| `tool_start` | Java | 工具开始执行 | ✅ 状态提示 |
| `tool_end` | Java | 工具执行完成 | ✅ 状态提示 |
| `error` | Java | 错误信息 | ✅ 错误提示 |
| `done` | Python | 流结束（Java 不转发给前端） | ❌ 内部使用 |

### 1.2 事件格式

```json
// 正文内容（增量）
{ "type": "content", "text": "计" }

// 思考过程（增量，仅 deep-thinking 模式）
{ "type": "reasoning", "text": "我需要先计算" }

// 工具开始执行
{ "type": "tool_start", "tool": "calculator", "args": { "expression": "2+3*4" } }

// 工具执行完成
{ "type": "tool_end", "tool": "calculator", "result": "14" }

// 错误
{ "type": "error", "message": "工具调用深度已达上限" }
```

```

  "result": "78.53975" }

                                              ↓
流结束                                         → 消息完成，可继续输入
```

## 三、前端状态管理

### 3.1 消息结构定义

```typescript
// 一条消息的完整类型
interface Message {
  role: 'user' | 'assistant';
  content: string;           // 正文（Markdown）
  reasoning?: string;        // 思考过程（仅在 deep-thinking 模式）
  toolCalls?: ToolCallGroup[]; // 工具调用记录
  isStreaming?: boolean;     // 是否仍在流式输出中
  error?: string;            // 错误信息
}

// 一组工具调用（同一轮可能调用多个工具）
interface ToolCallGroup {
  calls: ToolCallItem[];
}

// 单个工具调用
interface ToolCallItem {
  id: string;
  tool: string;              // 工具名称，如 "calculator"
  args: Record<string, any>; // 调用参数
  result?: string;           // 执行结果（tool_end 后才有）
  status: 'running' | 'done' | 'error';
}
```

### 3.2 状态转换

```
用户发送消息
    │
    ▼
新建 assistant 消息: { role: "assistant", content: "", isStreaming: true }
    │
    ├── 收到 reasoning → 追加到 reasoning 字段
    │
    ├── 收到 tool_start → 创建 ToolCallItem { status: "running" }
    │      追加到 toolCalls[0].calls[]
    │
    ├── 收到 tool_end → 更新 ToolCallItem.status = "done"
    │      填充 result 字段
    │
    ├── 收到 content → 追加到 content 字段
    │
    └── 流结束 → 设置 isStreaming = false
```

## 四、核心代码实现（React/TypeScript 示例）

### 4.1 SSE 读取与事件分发

```typescript
async function* readSSE(response: Response): AsyncGenerator<SseEvent> {
  const reader = response.body!.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop() || '';

    for (const line of lines) {
      const trimmed = line.trim();
      if (trimmed) {
        try {
          yield JSON.parse(trimmed) as SseEvent;
        } catch {
          // 非 JSON 行，跳过
        }
      }
    }
  }
}
```

### 4.2 事件处理主循环

```typescript
interface SseEvent {
  type: 'content' | 'reasoning' | 'tool_start' | 'tool_end' | 'error';
  text?: string;
  tool?: string;
  args?: Record<string, any>;
  result?: string;
  message?: string;
}

async function handleChatStream(
  conversationId: string,
  userMessage: string,
  options: {
    thinking?: boolean;
    enableTools?: boolean;
    toolNames?: string[];
  }
): Promise<Message> {

  const response = await fetch('/ai/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'Accept': 'text/event-stream' },
    body: JSON.stringify({
      conversationId,
      message: userMessage,
      enableTools: options.enableTools,
      toolNames: options.toolNames,
    }),
  });

  // 初始化 assistant 消息
  const message: Message = {
    role: 'assistant',
    content: '',
    reasoning: options.thinking ? '' : undefined,
    toolCalls: [],
    isStreaming: true,
  };

  // 当前正在接收的工具调用（tool_start 创建，tool_end 关闭）
  let currentToolIndex = 0;

  // 推送初始消息
  onMessageUpdate(message);

  for await (const event of readSSE(response)) {
    switch (event.type) {
      case 'content':
        message.content += event.text!;
        break;

      case 'reasoning':
        message.reasoning = (message.reasoning || '') + event.text!;
        break;

      case 'tool_start': {
        // 创建新的工具调用组（或追加到当前组）
        if (!message.toolCalls![currentToolIndex]) {
          message.toolCalls!.push({ calls: [] });
        }
        message.toolCalls![currentToolIndex].calls.push({
          id: crypto.randomUUID(),
          tool: event.tool!,
          args: event.args!,
          status: 'running',
        });
        break;
      }

      case 'tool_end': {
        // 找到对应的 running 状态调用并更新
        const group = message.toolCalls![currentToolIndex];
        if (group) {
          const call = group.calls.find(c => c.tool === event.tool && c.status === 'running');
          if (call) {
            call.result = event.result;
            call.status = 'done';
          }
        }
        // 检查当前组的所有调用是否都完成
        const allDone = group?.calls.every(c => c.status === 'done');
        if (allDone) {
          currentToolIndex++; // 准备接收下一轮工具调用
        }
        break;
      }

      case 'error':
        message.error = event.message;
        console.error('SSE error:', event.message);
        break;
    }

    // 每次事件后推送更新
    onMessageUpdate(message);
  }

  // 流结束
  message.isStreaming = false;
  onMessageComplete(message);
  return message;
}
```

### 4.3 工具调用卡片组件

```tsx
// ToolCallCard.tsx
interface ToolCallCardProps {
  call: ToolCallItem;
}

function ToolCallCard({ call }: ToolCallCardProps) {
  return (
    <div className={`tool-call-card status-${call.status}`}>
      <div className="tool-call-header">
        {call.status === 'running' ? (
          <SpinnerIcon className="spinning" />
        ) : call.status === 'done' ? (
          <CheckIcon />
        ) : (
          <ErrorIcon />
        )}
        <span className="tool-name">{call.tool}</span>
        <span className="tool-status">
          {call.status === 'running' ? '执行中...' :
           call.status === 'done' ? '已完成' : '出错'}
        </span>
      </div>
      <div className="tool-call-body">
        <div className="tool-args">
          <label>参数:</label>
          <code>{JSON.stringify(call.args)}</code>
        </div>
        {call.result && (
          <div className="tool-result">
            <label>结果:</label>
            <code>{call.result}</code>
          </div>
        )}
      </div>
    </div>
  );
}
```

### 4.4 消息气泡组件（整合版）

```tsx
// ChatMessage.tsx
function ChatMessage({ message, isStreaming }: { message: Message; isStreaming: boolean }) {
  return (
    <div className={`chat-message ${message.role}`}>
      {/* 深度思考区（可折叠） */}
      {message.reasoning && (
        <details className="reasoning-block" open={isStreaming}>
          <summary>💭 思考过程 {isStreaming && '(思考中...)'}</summary>
          <div className="reasoning-content">{message.reasoning}</div>
        </details>
      )}

      {/* 工具调用卡片 */}
      {message.toolCalls?.map((group, gi) => (
        <div key={gi} className="tool-call-group">
          {group.calls.map((call, ci) => (
            <ToolCallCard key={ci} call={call} />
          ))}
        </div>
      ))}

      {/* 正文 */}
      {message.content && (
        <div className="message-content">
          <Markdown text={message.content} />
        </div>
      )}

      {/* 流式输出中的光标 */}
      {isStreaming && !message.content && !message.toolCalls?.length && (
        <span className="cursor-blink">▊</span>
      )}

      {/* 错误信息 */}
      {message.error && (
        <div className="error-banner">⚠️ {message.error}</div>
      )}
    </div>
  );
}
```

## 七、错误处理

### 7.1 错误类型

| 场景 | 前端表现 |
|------|----------|
| 网络断开 | 消息停留在最后状态，显示"连接断开"提示 |
| 工具调用深度超限 | 收到 `{"type":"error","message":"工具调用次数过多"}` → 展示错误横幅 |
| 工具执行异常 | `tool_end` 的 `result` 字段是错误消息（如"计算错误: 除数不能为零"）→ AI 通常会自行修正 |
| 422 Unprocessable | HTTP 状态码错误，非 SSE 事件 → 弹窗提示配置错误 |

### 7.2 错误处理代码

```typescript
async function handleChatStream(...): Promise<Message> {
  const response = await fetch('/ai/chat', { ... });

  if (!response.ok) {
    // HTTP 级错误（如 422）
    const errorText = await response.text();
    throw new ChatError(response.status, errorText);
  }

  // SSE 正常处理...
  try {
    for await (const event of readSSE(response)) {
      // ... 处理事件
    }
  } catch (streamError) {
    message.error = '流被意外中断';
    message.isStreaming = false;
    onMessageUpdate(message);
  }

  return message;
}
```

## 八、性能注意事项

| 注意点 | 建议 |
|--------|------|
| 高频 `onMessageUpdate` 调用 | 使用 `requestAnimationFrame` 或 throttle（50ms）减少渲染次数 |
| 长 reasoning 文本 | 设置最大展开高度 + `overflow-y: auto` |
| 多消息列表滚动 | 流式输出时使用 `scrollIntoView({ behavior: 'smooth' })` |
| 内存泄漏 | 切换会话时 abort 正在进行的 fetch（`AbortController`） |
